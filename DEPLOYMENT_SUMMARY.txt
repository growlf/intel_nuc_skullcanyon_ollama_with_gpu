🎯 HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════

User Flow:
  1. User installs Opencode on their system
  2. User configures agent context URL (points to your AGENT_ORCHESTRATION.md)
  3. User starts agent
  4. Agent asks user to run: bash <(curl -s your-url/collect-state.sh)
  5. User runs script, copies JSON output
  6. Agent analyzes JSON, identifies issues
  7. Agent guides user step-by-step through fixes
  8. For each step: explain → approve → execute → verify
  9. Agent troubleshoots any failures
  10. Done! GPU acceleration working

Total time: 10-15 minutes (mostly waiting for Ollama install/restart)


🔄 AGENT DECISION FLOW
═══════════════════════════════════════════════════════════════════════════

Agent reads AGENT_ORCHESTRATION.md and follows this logic:

1. GPU type?
   ├─ Intel only → Continue (Intel path)
   ├─ AMD only → Continue (AMD path)
   ├─ Intel + AMD hybrid → Continue (both GPUs)
   └─ NVIDIA → STOP (nvidia-cuda-toolkit, out of scope)

2. Is GPU driver loaded (i915 for Intel / amdgpu for AMD)?
   ├─ YES → Continue  
   └─ NO → BLOCKER (install kernel updates or enable in BIOS)

3. Is render node available?
   ├─ YES → Continue
   └─ NO → BLOCKER (verify i915, check GPU in BIOS)

4. Is user in render group?
   ├─ YES → Continue
   └─ NO → ACTION (add user, ask to log out/back in)

5. Is Ollama installed?
   ├─ YES → Continue
   └─ NO → ACTION (install via curl)

6. Is Vulkan GPU configured?
   ├─ YES → Continue
   └─ NO → ACTION (create systemd override.conf)

7. Test GPU inference
   ├─ Works → SUCCESS!
   └─ Fails → TROUBLESHOOT (follow debugging steps)

Each decision maps to an action in AGENT_ORCHESTRATION.md.
